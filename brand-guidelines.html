09

DESIGN PRINCIPLES

Visual rules to maintain consistency across all screens and future features.

DO

  • Use uppercase text for all UI labels and buttons
  • Apply generous letter-spacing (1–4px) on display text
  • Keep surfaces dark and layered — never flat white
  • Use player colors only for player-owned elements
  • Use accent yellow sparingly for primary CTAs
  • Maintain 2px gap grid system on the board
  • Use 1px borders with $border-primary for separation
  • Let IBM Plex Mono handle data and descriptions

DON'T

  • Mix player colors — cyan is P1, red is P2, always
  • Use accent yellow for non-interactive decoration
  • Add rounded corners — all elements use sharp edges
  • Use more than three text hierarchy levels per screen
  • Introduce new colors outside the design token system
  • Use sentence case in navigation or game UI
  • Apply heavy drop shadows — depth comes from value shifts
  • Combine Space Grotesk body text with IBM Plex Mono headers
